# Changelog

All notable changes are documented here.

## [0.1.0] - 2026-07-23

### Added

- Streaming CSV profiling for UTF-8 and UTF-8 BOM files.
- Deterministic snapshot schema v1 and SHA-256 content identification.
- Integer, float, boolean, date, datetime, string, null, and mixed inference.
- Exact distinct counts backed by temporary SQLite storage.
- Schema, volume, missingness, numeric, string, temporal, and configured quality rules.
- Terminal, JSON, and Markdown reports with CI exit codes.
- Pydantic-validated TOML configuration.
- Cross-platform CI, package build checks, wheel smoke tests, dogfooding, and benchmarks.
- Privacy, security, performance, configuration, type, drift, and limitation documentation.
